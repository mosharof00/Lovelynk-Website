# LoveLynk Website — Build 3.0

The latest LoveLynk marketing website. This build is based on Build 2.9 and keeps all previous landing-page, widget preview, and two-phone visual enhancements.

## Build 3.0 changes

- Unified pricing and benefits into one white rounded card on the light-blue website background.
- Reduced repeated subscription messaging to one headline and three benefits.
- Maintained the interactive annual/monthly price switch and all existing pricing IDs and JS.
- Streamlined per-person savings, trial and subscription disclaimer.
- Replaced the pricing button copy with **Start your free trial** while preserving its existing download anchor.
- Created responsive one-column mobile layout with centered typography, a single contained card and no nested borders.

## Files

Open `index.html` locally for a basic review or deploy all website files together. The separate `LoveLynk-Website-Interactive-Preview-2.9.html` is a self-contained preview. Set real app marketplace URLs in `store-links.js` before public launch.

## Pricing

- Annual: £19.99/year per couple (approx. £1.67/month; £0.83/month per person)
- Monthly: £4.99/month per couple (£2.50/month per person after rounding)
- 7-day free trial (subject to your configured store subscription products)
